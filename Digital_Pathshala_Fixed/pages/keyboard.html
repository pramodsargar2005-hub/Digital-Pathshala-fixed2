⌨️ Keyboard & Mouse

Learn how to use a keyboard and mouse. Practice typing, understand important keys and discover how to control a computer easily.

What is a Keyboard?

A keyboard is an input device used to enter letters, numbers and symbols into a computer.

We use a keyboard to type our names, write documents, enter numbers and give instructions to a computer.

💡 Did You Know?

The keyboard is one of the most commonly used input devices in a computer.

🔤 Different Types of Keyboard Keys

A keyboard has different types of keys. Each key has a specific purpose.

🔠

Alphabet Keys

🖱️ What is a Mouse?

A mouse is an input device used to move the pointer on a computer screen.

It helps us select files, open applications, click buttons and drag objects.

👆

Left Click

Used to select files, buttons and objects. Double-clicking can open files and applications.

🖱️

Right Click

Opens a menu with additional options for a selected item.

🔄

Scroll Wheel

Used to move up and down through a document or webpage.

🌟 Tips for Beginners

✔ Sit comfortably while using a computer.
✔ Keep your fingers relaxed while typing.
✔ Practice typing every day.
✔ Use the mouse gently.
✔ Take short breaks while learning.
