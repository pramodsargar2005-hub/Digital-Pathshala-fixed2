💻 Computer Basics

Welcome to your first computer lesson! Let's understand what a computer is, how it works and what its main parts do.

What is a Computer?

A computer is an electronic machine that accepts data, processes it and gives us useful information.

We can use computers to study, write, draw pictures, calculate numbers, watch videos and communicate with others.

Example: When you type 5 + 5 into a calculator on a computer, it processes the numbers and displays the answer 10.

🖥️ Main Parts of a Computer

A desktop computer has several important parts that work together.

🖥️

Monitor

Displays text, pictures, videos and other information.

⌨️

Keyboard

Used to type letters, numbers and symbols.

🖱️

Mouse

Helps us point, click, select and move items.

🗄️

CPU

The processor executes instructions and processes data.

🔊

Speakers

Produce sound, music and other audio.

🖨️

Printer

Prints documents and pictures on paper.

⚙️ Hardware and Software

🖥️

Computer Hardware

Hardware means the physical parts of a computer that we can see and touch.

Examples: Monitor, keyboard, mouse, CPU, printer and speakers.
💿

Computer Software

Software is a set of programs or instructions that tells a computer what to do.

Examples: Windows, Paint, MS Word and web browsers.

🧑‍💻 Types of Computers

🖥️

Desktop

A computer designed to be used at a desk.

💻

Laptop

A portable computer that we can carry.

📱

Tablet

A portable touchscreen computing device.

🌟 Learning Tip

Try to identify a monitor, keyboard, mouse and CPU in your school computer lab. Learning by practicing makes it easier to remember computer parts.
