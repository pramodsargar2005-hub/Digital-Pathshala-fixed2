PRACTICE ON THIS COMPUTER

File lab

फोल्डर बनाओ और फाइल भेजो

A folder is a bag for your work. A file is one piece of work inside that bag.

Checking the class server…

1. Folder

Give it a clear name, such as My Homework or Class 6 Drawings.

2. File

A file can be a text page, a picture, or a PDF. Send school work only.

3. Send

Sending here means the file is copied into the class folder on this computer.

Create a folder

नया फोल्डर बनाओ

  1. Think of a short name.
  2. Type it in the box.
  3. Press Create folder.

Send a file

फाइल कक्षा में भेजो

Allowed files: txt, pdf, png, jpg, doc, ppt. Biggest size: 5 MB. Files stay on this class computer.
